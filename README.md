# ML Weather Predictor

Live Demo: https://weather-ai-vert.vercel.app/

Backend API: https://weather-ai-backend-hn4p.onrender.com/docs

## Features

- Live weather data using OpenWeather API
- ML-based rain prediction
- FastAPI backend
- Modern responsive frontend
- Real-time city weather search

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- FastAPI
- Scikit-learn
- NumPy

Deployment:
- Vercel
- Render

## ML Model

Current model:
- Logistic Regression

Prediction target:
- Rain likelihood
